机器人强化学习中的 PPO：从价值估计到策略更新

发表于2026-05-29|更新于2026-10-28|理论与方法强化学习
|总字数:12.2k|阅读时长:42分钟|浏览量:

机器人执行动作，环境返回奖励；优化器更新的却是策略网络参数。奖励怎样变成参数的梯度，中间要经过回报、价值估计和优势函数。理解这条计算过程后，才能说清 GAE 改善了什么、PPO 的裁剪限制了什么，以及为什么它适合大量并行的机器人仿真训练。

本文按基本概念、Bellman 方程、TD、策略梯度和 Actor–Critic 的顺序展开，参考赵世钰老师《强化学习的数学原理》的讲解脉络。数值例子独立编写；TRPO、PPO 与 SAC 放在同一条参数更新主线上对照，较长的实现推导折叠供选读。教材与课程官方入口

1. 状态、动作、策略与参数，各是什么

动作是某一次决策的结果。网络参数改变后，以后遇到状态时的动作分布会改变；已经执行过的那个动作，仍然是经验记录中的原值。后面会把这个区别算出来。

为了先讲清数学，前半篇假定状态可以完整观察。真实机器人 actor 一般只能看到观测 o，例如编码器、IMU 和动作历史；训练 critic 可以额外获得仿真状态。这个信息差在工程中要处理，暂时不与价值函数的定义混在一起。

Bellman 方程提供了“如何把相邻时刻的价值联系起来”的规则。它不是另给价值贴一个定义，也不是知道下一状态之后，就已经知道了整个未来。实际算法仍要估计右侧的 V。

5. 不知道真实 V，critic 怎么学：从 MC 到 TD error

等回合结束再评分：Monte Carlo

前面 V 和 Q 的定义都包含平均未来回报。一个直接方法是多跑几次，记录每次真实发生的 G，再让网络拟合这些回报。这个价值网络通常称为 critic，用 phi 表示它的参数：

例如真的执行 a₊，看到后续奖励 1、10，就能算出 G_0=10，拿它作为本次拟合目标。另一回合执行 a₋，目标为 6；两个动作各占一半时，同一状态的平方误差回归会趋向平均值 8。

这种方法要等后面的奖励发生，而且不同回合的累计结果可能波动很大。

只等一步：Temporal Difference

Bellman 方程提示我们：既然还没看到完整未来，可以先用下一状态的价值估计代替它。用这一步真实奖励，加上下一状态的估计，构成 TD target：

再用“新目标减旧预测”，得到 TD error：

TD 是 temporal difference，指利用相邻时刻的价值关系更新估计。它不只是 下一步 V − 当前 V，还必须包括眼前奖励和折扣。

例如当前估计 V(s)=8、下一状态估计 V(s₁)=9。这次执行 a₊，得到 r=1，则 TD target 为 1 + 0.9 × 9 = 9.1，TD error 为 9.1 − 8 = 1.1。这条经验告诉 critic：这次观察得到的目标，比刚才的预测高 1.1。

它与上面的 TD error 累加完全相同，因为两步估计就是 delta₀ + gamma × delta₁。展开到更长的轨迹时，多步估计的权重按 lambda 衰减，整理后就得到前面的 GAE 和式；有限轨迹最后一项要保留剩余权重，并正确处理终止或 bootstrap。

lambda 较小，更多依赖短步 critic 预测，通常采样波动较小，但更容易受价值估计偏差影响；lambda 较大，更多采用后面实际发生的奖励，减轻这种依赖，也可能带入更多轨迹噪声。GAE 改善的是“这次动作该怎样评分”的估计，不负责限制网络更新幅度，也不是 PPO 独有的组件。

8. 为什么优化网络参数，而不是把 action 改好

现在已经有了某次执行记录，以及“这次选择相对平均水平怎样”的估计。接下来需要把这个评价用来改变选动作的规则。

PPO 优化器持有的是 actor 的网络参数 theta。过去执行过的 a 是训练数据，给它改个数值，不会改掉机器人已经发生过的运动；而部署时机器人还会遇到其他状态，需要网络继续产生动作。

用连续动作的最小例子看梯度。固定当前状态，只让策略的均值 mu 可训练，标准差 sigma=0.5 不训练；mu 就是这个玩具策略的唯一参数。采集时 mu=0，恰好采到了 a=0.5。其对数概率密度满足：

PPO 和 GAE 分别解决哪一步的问题

前面的两个问题到这里才接在一起：GAE 负责估计优势，PPO-Clip 根据这个优势更新策略，同时抑制对同一批旧数据的过度优化。 前者在处理评分的偏差与方差，后者在处理新旧策略偏离。两者经常一起用，但不能互相替代。

例如 critic 严重高估后续价值，就可能给一个长期吃亏的动作算出正优势。clip 仍会按这个正优势鼓励提高动作概率，只是在超过阈值后不再增加这条样本的目标收益；它不会自动发现评分算错了。反过来，即使优势估计准确，没有更新约束也可能一次把策略改得过远。

PPO 的好处，放到全身控制训练里看

相对直接反复优化普通策略梯度，PPO 给一批数据的多次利用加了约束。 普通目标里的 ratio × advantage 可以随着某个正优势动作的概率继续增大；但优势来自旧策略，不能一直当成当前策略的可靠评分。PPO 在有利方向超过阈值后去掉继续提高该样本目标的激励，因此可以在一批经验上做有限轮更新，再换新数据。这是批内复用；它没有把 PPO 变成可以长期回放任意旧经验的 off-policy 算法。

相对 TRPO，PPO 保留了控制策略变化的意图，更新过程更容易实现。 上面的 actor loss 直接交给 Adam，不需要求共轭梯度方向和反复线搜索。对全身控制实验，修改观测、网络或加入辅助损失后，仍可沿用这套一阶优化流程。代价是 clip 只作用于替代目标，没有 TRPO 那样显式检查的 KL 约束，更不保证每次真实回报都提高。

它也适合这里“大量并行仿真、短段采集、整批更新”的组织方式。 actor 一次输出整组关节的连续分布，不需要枚举关节动作组合；critic 帮助从短段经验构造学习目标。训练时给 critic 更多仿真信息、给 actor 部署能获得的观测，也能接入这套流程。不过连续策略、并行仿真和非对称 actor–critic 都不是 PPO 独占的能力，不能把这些工程选择都算成 clip 的贡献。

这里的适用条件是仿真能持续提供新数据。如果每条经验都要由真机采集，PPO 更新几轮就换新数据的成本会更突出，SAC 一类经验回放方法就值得比较。不能仅凭 PPO 在仿真里常用，就断言它比 SAC 更省样本或部署更安全。

采样量和优化量要分开算。 每个 minibatch 有 24,576 条经验，5 轮让同一批经验各参与 5 次训练，总计 491,520 次样本使用；新采集的数据仍只有 98,304 条。每组的 old_logp 和优势在这些更新中固定。继续增加 epoch，增加的是计算和旧数据使用次数，不能当成获得了更多经验；新旧策略偏离太大时，旧优势也越来越不适合指导当前策略。

仿真频率为 200 Hz、每 4 个物理步执行一次策略，策略间隔为 0.02 s；24 步对应每个环境 0.48 s 的采样片段，而不是一整段任务。没有终止时，片段尾部通过 critic 的价值预测接上更远的未来，所以短片段也能训练长期任务，前提是 bootstrap 和终止处理正确。

这组 GAE 参数给出 gamma × lambda = 0.9405。后面第 10 步的 TD error，传到当前优势时乘约 0.541；第 20 步乘约 0.293。它们分别相隔 0.2 s 和 0.4 s：后续修正能传回来，但越远越弱。这些是 TD error 的权重，不是把 0.4 s 之后的奖励丢掉。 奖励仍按 gamma 折扣，更远的价值还会通过 bootstrap 进入估计；lambda 也不是机器人的控制频率或固定规划时域。

clip 之外，这份实现还根据实际高斯分布的平均 KL 调学习率。KL 大于 0.02 时学习率除以 1.5；处于 0 到 0.005 之间时乘以 1.5。它针对的是“这一批参数改得快不快”，与 GAE 针对的“评分是否可靠”分工不同。

训练不稳时，怎样沿着这条逻辑查

如果 KL 突然变大，应先检查学习率、每批更新轮数以及动作分布的标准差；clip 不是硬约束，不能因为 epsilon=0.2 就认定策略变化已被锁住。如果还记录了裁剪比例，要先看日志统计的是“ratio 越界”，还是“目标真正进入裁剪平台”，两者不等价。大量样本越界时，继续堆 epoch 未必能学到更多。

如果 KL 很小，跟踪效果却一直不改善，就不能只缩小更新。要回到评分这一侧，检查 critic 对回报目标的拟合、优势的分布、摔倒与超时的处理，以及各项奖励是否把好行为评成了高分。价值损失下降只说明更接近当前目标；目标算错，它也可以下降。本文后面的奖励表就是为了把这个评分来源拆开看。

如果仿真回报很好、机器人仍然抖动或接触失败，则要继续检查动作尺度、PD、力矩饱和与碰撞模型。PPO 能优化给定仿真和奖励中的策略，不能替代执行器建模，也不会由 clip 自动产生柔顺性。需要比较算法时，应在相同任务、奖励和评估条件下分别记录采样量、耗时、跟踪误差和失败率；这里的配置计算本身不能证明哪个算法效果更好。

选读：FALCON 实现中的分组 PPO、KL 和超时处理

FALCON 分组控制实现对各控制组分别维护 actor、critic 与优化器，每组内先对动作维度求联合 log probability；没有把每个关节当成独立 PPO 样本。它先给 ratio×advantage 取负号，再取 maximum，与上文取 minimum 后加负号等价。

更新时用新旧高斯均值和标准差计算解析 KL。学习率按上文阈值调整，并限制在 1e−5 到 1e−2。这个机制调整后续更新速度，不撤回刚才的参数。

实现将超时补偿先加进 reward，再用 done 截断 GAE；严格的最终状态 bootstrap 要使用截断前的下一状态价值，而不是自动 reset 后的价值。应核对补偿读取 value 的具体时刻。

每个控制组独立计算自己的优势与联合概率比率。上文的 20 次更新是每组的更新次数，不表示把每个关节分别更新 20 次，也不表示执行了 20 次物理控制。

面试问“为什么选 PPO”，可以怎样回答

对这里的全身控制仿真，首先需要用经验判断动作的长期好坏：critic 估计 V，TD error 提供一步修正，GAE 把不同步数的修正组合起来，在价值估计偏差与轨迹噪声之间折中。然后才是更新策略：PPO 用新旧动作概率比率乘优势，并通过 clip 抑制一批旧数据上的过度优化，因此能够对同一批经验做有限轮 minibatch 更新。相比 TRPO，它可以直接使用一阶优化器，实现和修改都更方便。

具体到这组配置，4096 个环境各采 24 步，每批 98,304 条经验，分 4 个 minibatch 训练 5 轮；gamma=0.99、lambda=0.95、epsilon=0.2，并用 KL 调整学习率。这与并行仿真不断提供新数据的方式相配合。但 GAE 不是 PPO 独有的，clip 也不保证回报单调上升；真机数据昂贵时还要比较 SAC 的回放收益，动作尺度和接触模型仍需单独验证。

PPO 的批内复用仍受新旧策略差异限制。接下来换一个问题：如果希望更长期地保留经验，怎样在旧状态上评价当前策略新产生的动作？这就引出了 SAC 的 Q 网络和经验回放。

12. SAC 是什么：让旧经验留下来，学习动作价值 Q

PPO 的 critic 主要估计状态价值 V，帮助构造优势；更新 actor 时评价的是本轮执行过的动作。SAC 则学习动作价值 Q(s,a)，把状态转移长期保存在经验回放 replay 中，并反复抽样更新。

actor 在 replay 抽出的状态上重新产生一个动作，交给可求导的 Q 网络评价，再根据这个评价更新自身参数。这里的新动作可以处在梯度路径上，但优化器更新的仍是 actor 参数；replay 中机器人过去真正执行的动作不会被改写。

SAC 还把熵纳入目标，控制追求高回报与保留探索之间的权衡。它不需要 PPO 的 old_logp 比率，但增加了 Q 估计、目标网络、回放分布与温度之间的耦合。先理解到这一步，再看下面的完整方程即可。

motion_global_body_lin_vel 比较世界系身体线速度，三轴平方和后对身体平均；1 m/s 是误差尺度。位置很接近但身体仍在快速冲过目标时，这项会降低奖励。

motion_global_body_ang_vel

motion_global_body_ang_vel 比较世界系身体角速度。3.14 rad/s 是指数核尺度，不是机器人最大允许角速度。它补充姿态项，但不能替代力矩限制。

action_rate_l2

Holosoma 的 action_rate_l2 返回连续两次动作之差的平方和，配置乘负权重。它没有除以控制周期，因此不是物理意义上的关节加速度。动作幅度和控制频率变化后，同一系数的效果也会变。

limits_dof_pos

Holosoma 的 limits_dof_pos 对上下软限位之外的距离取正部，按关节相加。原始量非负、权重为负，且这里不是平方惩罚。它是奖励代价，不能替代执行器硬限位。 本预设以关节硬范围中点为中心，将半宽乘 0.9 得到软限位；参数来自该奖励自己的 soft_dof_pos_limit。

undesired_contacts

Holosoma 的 UndesiredContacts 先在接触历史窗取每个身体的力范数峰值，超过 1 N 的身体记为 1，再求和。脚和允许接触的部位必须从筛选集合排除；阈值判断意味着超过 1 N 与超过 100 N 对同一个身体贡献一样。

环境奖励和优化器损失分两层看

FALCON 的分组全身控制 PPO 中，clip 参数是 0.2、value loss coefficient 为 1.0、entropy coefficient 为 0.01；它们进入参数更新目标，不应塞进环境奖励表当作每步机器人奖励。TRPO 的 KL 阈值、SAC 的温度同样属于优化规则。SAC 若自动学习温度，不能拿初始温度当成训练全程不变的常数。

相对原生算法，当前讨论的工程差异包括分组 critic／动作接口、回报处理和任务预设。它们不改变“PPO 使用同批 rollout 的概率比率，SAC 从 replay 中学习双 Q”这两个核心机制。机器人型号、action scale 和控制周期改变后，奖励分布也会改变，直接复用一组损失系数不保证同样稳定。
